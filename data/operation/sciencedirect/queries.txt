I've collected the short ScienceDirect queries I used and left a few notes so I (or anyone else) can reproduce the searches later.

How I run these searches
- Copy one line (either the COMPACT or the STRICT version) and paste it into ScienceDirect's Title/Abstract/Keywords field.
- Run each method as a separate search — I run one query at a time and export the results for that method.
- Save each export under `data/operation/sciencedirect/` with a clear, descriptive filename (for example: `sciencedirect_mpc_2025-12-13.csv`).
- I typically filter to years 2015–2025 and restrict results to Article/Journal to keep the set relevant.
